# Security notes

このツールはローカルで企業データを処理します。入力ファイル、SQLite、CSV出力、APIキャッシュ、秘密値を公開リポジトリへ追加しないでください。

公式サイト巡回機能は、公開マスタで確認されたURLだけを対象にし、同一ホスト制約とプライベートネットワーク拒否を実装しています。それでも、信頼できない入力でネットワークアクセス機能を動かす場合は、専用ユーザー、コンテナ、送信先制御のあるネットワークで実行してください。

脆弱性報告には、秘密値、個人情報、入力企業データ、取得済みキャッシュを添付しないでください。再現には最小限の合成データを使用してください。
