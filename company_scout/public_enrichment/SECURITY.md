# Security notes

このツールはローカルで企業データを処理します。入力ファイル、SQLite、CSV出力、APIキャッシュ、秘密値を公開リポジトリへ追加しないでください。

公開repositoryのActionsで企業行、manifest、progress、候補、merge結果をjob間またはrun間へ渡す場合は、32文字以上のrepository secret `G_CONTACT_ARTIFACT_KEY` を必須にし、AES-256-CBC/PBKDF2で暗号化した単一archiveだけをuploadしてください。平文artifactやwildcardによる作業ディレクトリ全体のuploadは禁止します。

公式サイト巡回機能は、公開マスタで確認されたURLだけを対象にし、同一ホスト制約とプライベートネットワーク拒否を実装しています。DNS結果は全IPがpublicであることを確認し、そのスナップショットのIPへ接続先を固定したまま元のHost、TLS SNI、証明書名を検証します。proxy経由は許可しません。それでも、信頼できない入力でネットワークアクセス機能を動かす場合は、専用ユーザー、コンテナ、送信先制御のあるネットワークで実行してください。

脆弱性報告には、秘密値、個人情報、入力企業データ、取得済みキャッシュを添付しないでください。再現には最小限の合成データを使用してください。
